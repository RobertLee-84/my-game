💾 독립 세이브 슬롯 & 파일 백업 매니저

브라우저 기본 자동 저장(IndexedDB) 외에 원하는 시점마다 별도 슬롯이나 PC 파일로 영구 보관하세요.

💡 게임 안에서 먼저 저장(Save)을 실행한 뒤 슬롯 백업이나 파일 내보내기를 누르면 가장 정확합니다.

🚀 GitHub Pages 배포 및 게임 파일 등록 방법

water2.dist.be처럼 나만의 웹 주소로 고전 게임을 배포하는 구조입니다.

1. 폴더 구조 (GitHub 저장소 루트)

my-retro-games/
├── index.html          # 지금 보시는 이 웹 런처 파일 (이름을 index.html로 변경)
└── games/              # 게임 압축 파일(.zip)을 넣는 폴더
    ├── fd2.zip         # 용의기사 2 (내부에 FD2.EXE 포함)
    ├── water2.zip      # 대항해시대 2 (내부에 KOEI.COM 또는 PLAY.BAT 포함)
    └── custom.zip      # 기타 추가하고 싶은 고전 게임

2. 터미널 원클릭 GitHub 푸시 명령어

git init
git checkout -b main
git add .
git commit -m "feat: Retro DOS web launcher with Flame Dragon 2 & Save Manager"
git remote add origin https://github.com/내아이디/내저장소이름.git
git push -u origin main

푸시 후 GitHub 저장소의 Settings → Pages → Branch: main (/root)를 선택하고 Save를 누르면 1분 뒤 https://내아이디.github.io/내저장소이름/ 주소로 사이트가 개설됩니다.
