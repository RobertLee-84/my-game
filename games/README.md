# 게임 ZIP 파일 보관 폴더 (games/)

이 폴더에 보유하신 도스 고전 게임 압축 파일(`.zip`)을 아래 파일명으로 넣어주시면 웹사이트에서 서버 모드로 즉시 실행됩니다:

- `fd2.zip` : 용의기사 2 (내부에 `FD2.EXE` 포함)
- `water2.zip` : 대항해시대 2 (내부에 `KOEI.COM` 또는 `PLAY.BAT` 포함)
- `custom.zip` : 삼국지 3, 프린세스 메이커 2 등 기타 도스 게임

※ 이 폴더에 파일을 넣지 않아도 웹사이트 접속 후 [내 PC에서 ZIP 선택] 버튼으로 내 컴퓨터의 `.zip` 파일을 바로 불러와 실행하고 저장할 수 있습니다.
